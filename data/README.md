# Dataset

This project uses the **UCI Default of Credit Card Clients** dataset.

## Source

UCI Machine Learning Repository

- Dataset ID: 350
- DOI: 10.24432/C55S3H

The dataset is not included in this repository.

The dataset can be accessed through the official UCI Machine Learning Repository.

## Dataset Description

The dataset contains information about credit-card clients and a binary target indicating whether the client defaulted on their payment in the following month.

The dataset contains:

- 30,000 observations
- 23 explanatory features
- 1 binary target variable

The project uses the dataset for studying machine-learning robustness under missing data, feature outliers, and label noise.
